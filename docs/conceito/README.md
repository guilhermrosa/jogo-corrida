# Arte conceitual do mundo

Esboços para escolher a direção visual e estilística do **mundo** do jogo
(não do jogo em si: o jogo é adaptado depois, conversando sobre cada mudança).
A identidade de jogo continua descendendo do MK64.

Direção pedida: steampunk, fantástico e encantador (whimsical), com uma pitada do jeito
desengonçado e cartunesco de jogos de plataforma dos anos 90.

As imagens foram geradas por IA no Canva. Aqui ficam **prévias pequenas** (200 px);
a versão grande (2048 px) abre pelos links.
