# Registro visual dos pilotos

Folhas com os 8 pilotos em vários ângulos e poses, para comparar a evolução do visual.

Colunas: de costas, 3/4, lado, frente, 3/4 de frente, comemorando, atordoado e virando.
Linhas: Pipoca, Tico, Mel, Faísca, Bento, Tonho, Rino e Juca.

| Arquivo | Versão |
|---|---|
| `v1-antigos.png` | Primeira versão: 16 ângulos x 3 poses, sprites de 64 px (ampliados para comparar) |
| `v2-novos.png` | Segunda versão: corpo inteiro, rostos com expressão, Tico sapo-cogumelo; 32 ângulos x 5 poses, sprites de 96 px |
| `comparativo-v1-v2.png` | As duas lado a lado |
| `v3-olhos.png` | Terceira versão: olhos simples (oval escuro com brilho, sem globo branco nem íris colorida), Tico com olhos no rosto, Juca com olhar semicerrado; Rino igual |
| `v3-rostos.png` | Close dos rostos da v3: normal, comemorando e atordoado |
| `comparativo-v2-v3.png` | v2 e v3 lado a lado |

Na v1 não existiam as poses de comemorar e atordoado; os ângulos da v1 são os mais próximos disponíveis.
